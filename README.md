Relevant Instructions to use Application

Download the “Expo Go” application on your respective mobile device (Android or iOS).
Create an account on the “Expo Go” application on your mobile device.
Ensure that your computer and mobile device is connected to the same local network
Setting the terminal directory as the “orbital-app” folder, run the following code in the terminal: “expo start”. If app does not run after running this code, enter the following code instead: “npx expo start --tunnel” (ensure that Node.js, npm and expo is installed on your computer)
The screen on your mobile device should automatically be redirected to the Login page of our SilverLink mobile application.
